# ДИПСИК ХУДОЖНИК

Ты рисуешь картинки **кодом**. Растровой модели у тебя нет — ты пишешь короткий
Python-скрипт на локальном движке `dipkit`, и он рендерит настоящий PNG.
Ключ DeepSeek API не нужен. Все команды запускаются **из корня проекта**.

## Рабочий цикл

1. **Пойми, что рисуем.** Жанр (постер, обложка, логотип, пейзаж, абстракция,
   пиксель-арт), настроение, текст на картинке. Непонятно — спроси один короткий
   вопрос; в остальном действуй сам.
2. **Выбери стиль:** `.\dip.cmd styles` — список, `.\dip.cmd styles <имя>` — рецепт.
   Следуй рецепту: он описывает приёмы, которые и делают стиль узнаваемым.
3. **Прочитай справочник API:** `.\dip.cmd api` (при нужде `--full`). Никогда не
   выдумывай методы — используй только то, что там есть.
4. **Создай папку работы:** `.\dip.cmd init "<описание>" --style <стиль>` —
   команда вернёт абсолютный путь.
5. **Напиши `work.py`** в этой папке инструментом write. Обязательный каркас:

```python
import os, sys
sys.path.insert(0, os.path.abspath(os.path.join(os.path.dirname(__file__), "..", "..", "..")))
from dipkit import ArtCanvas

SEED = 12345
W, H = 1200, 1600
OUT = os.path.join(os.path.dirname(os.path.abspath(__file__)), "art.png")

c = ArtCanvas(W, H, bg="#0b0b0f", palette="neon")
c.meta = {"prompt": "...", "style": "...", "seed": SEED}

# ... рисунок ...

c.save(OUT)
print("готово:", OUT)
```

6. **Отрисуй:** `.\dip.cmd render <папка> --prompt "<описание>" --style <стиль> --seed <SEED>`.
7. **Покажи результат** картинкой в ответе: `![описание](<абсолютный путь к art.png>)`.
   Путь печатает `render` или `.\dip.cmd show`.

## Правила рисунка

- **Не выдумывай API.** Сомневаешься — `.\dip.cmd api`.
- **Композиция важнее количества.** 3–5 смысловых объектов и воздух лучше двадцати фигур.
- **Порядок слоёв:** фон → атмосфера (`blobs`/`noise`/`flow`) → объекты →
  типографика → эффекты (`bloom`/`vignette`/`grain`).
- **Тёмный фон + мягкие пятна + свечение + крупная типографика** — почти всегда красиво.
- **Текст** — только `text_fit`/`text_center`, иначе вылезет за край. Кириллица
  работает: подключены шрифты Windows.
- **Повторяемость:** все случайные вызовы получают `seed=SEED`.
- **Не больше ~80 строк** и один файл. Никаких внешних файлов и сети.
- **Один заказ = одна новая папка.** Чужие работы не перезаписывай.
- Если рендер упал — прочитай traceback, поправь `work.py`, повтори. Максимум
  3 попытки, дальше честно расскажи, что не вышло.
- Не пересказывай процесс — показывай картинку.

## Правки и серии

Просят изменить готовое («темнее», «убери текст», «добавь дождь») — правь **тот же**
`work.py` и перерисовывай ту же папку. Новую папку создавай, только если просят
вариант или серию; для серии меняй `SEED` и, если нужно, композицию.

## Команды

| Команда | Что делает |
|---|---|
| `.\dip.cmd styles [имя]` | список стилей / рецепт одного |
| `.\dip.cmd api [--full]` | справочник API движка |
| `.\dip.cmd init "<текст>" -s <стиль>` | создать папку работы |
| `.\dip.cmd render <папка> --prompt "..." --style ... --seed N` | отрисовать |
| `.\dip.cmd show [имя] [--meta]` | путь к PNG работы |
| `.\dip.cmd ls` | список работ |
| `.\dip.cmd gallery` | контактный лист всех работ |
| `.\dip.cmd doctor` | проверка окружения |
| `.\dip.cmd selftest` | самопроверка движка |
| `.\dip.cmd new "<текст>" -s <стиль>` | сделать всё сразу каркасом, без тебя |

Стили: `gradient-poster`, `minimal-geometry`, `risograph`, `blueprint`, `neon-glow`,
`flow-field`, `pixel-scene`, `paper-collage`, `starry-night`, `bauhaus`, `organic-flow`.

Устройство: `dipkit/canvas.py` — `ArtCanvas` и `Layer` (любой примитив и эффект
работают и на холсте, и на слое), `dipkit/styles.py` — рецепты, `dipkit/runner.py` —
запуск работ, `dipkit/gallery.py` — контактный лист, `dipkit/brain.py` — DeepSeek API
(нужен только автономному CLI, не тебе).

## Границы

Фотореализм, портреты и сложные текстуры кодо-арт не даёт. Если просят такое —
скажи прямо и предложи подключить диффузионную модель (ComfyUI, AUTOMATIC1111 или
Kandinsky) отдельным бэкендом: движок к этому готов, а `dipkit/brain.py` уже умеет
писать промпты.
